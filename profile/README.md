# Moguri

Moguri is built in the open by [Synctune](https://github.com/synctune-io), focused on developer tools for AI-assisted engineering. We put models, tools, and execution environments under the developer's control.

## Projects

| Repository | Focus |
| --- | --- |
| [moguri-website](https://github.com/moguri-dev/moguri-website) | The Moguri website with docs. |
| [moguri-desktop](https://github.com/moguri-dev/moguri-desktop) | The Moguri desktop application. |
| [moguri-tui](https://github.com/moguri-dev/moguri-tui) | The terminal interface for the Moguri AI harness. |
| [moguri-android](https://github.com/moguri-dev/moguri-android) | Code and APK for the Moguri mobile app |
| [moguri-ios](https://github.com/moguri-dev/moguri-ios) | Coming soon. Currently blocked by lack of hardware to test it and no Apple dev subscription. |
| [moguri-sdk](https://github.com/moguri-dev/moguri-sdk) | Shared APIs and integrations for building on Moguri. |
| [moguri-ssh](https://github.com/moguri-dev/moguri-ssh) | SSH integration for remote development. |
| [moguri-sandbox](https://github.com/moguri-dev/moguri-sandbox) | Isolated environments for agentic development, renamed from `sendbox`. |
| [moguri-vsx-extension](https://github.com/moguri-dev/moguri-vsx-extension) | An extension for VSCode compatible IDEs (VSX). |
| [moguri-ide](https://github.com/moguri-dev/moguri-ide) | An experimental AI-assisted IDE, with built in local model loading. |
| [moguri-assistant](https://github.com/moguri-dev/moguri-assistant) | An experimental AI-assistant, powered by the Moguri SDK, capable of managing calendars, sending and receiving messages from different channels and coding |
